# Changelog

All notable changes to GenSurf. Versions follow the addon version in
`package.xml`; the format follows [Keep a Changelog](https://keepachangelog.com/).
Entries before 0.29 are back-filled from the git history and use the
current names of the operators.

## [Unreleased]

### Changed — GenSurf's own vocabulary and toolbar structure

Documents saved with earlier versions open unchanged: every rename below
is migrated automatically when the document loads (types, properties,
option values and expressions), and the objects recompute identically.

| Before | Now |
|---|---|
| Geometrical Set | Construction Set (plus a new **Set Active** command) |
| Multi-Sections (loft) | Loft; its guides are now **rails** (`Rails`, `RailSupports`, `RailSupportRows`, `RailContinuities`) |
| Sweep Explicit / Line / Circle / Conic | Sweep Curve / Sweep Ruled / Sweep Arc / Sweep Conic; `Subtype` → `Mode`, `Guide1…5` → `Rail1…5`, Conic `Tangency1/2` → `TangentSurface1/2` |
| Sweep modes: With reference surface / With two guide curves / With pulling direction | 1 rail / 2 rails / Rail + direction |
| Two limits / Limit and middle / With reference surface / With draft direction | Between rails / Rail 2 as middle / Angle to surface / Draft from direction |
| Three guides / Two guides and radius / Center and radius / Center and two angles | Through 3 rails / 2 rails + radius / Center rail + radius / Center rail + angles |
| Two guide curves / Five guide curves | Tangent to 2 surfaces / Through 5 rails |
| Connect Curve | Bridge Curve |
| Corner (Corner On Support / 3D Corner) | Curve Fillet (`FilletPlane`: Support plane / Curves' plane) |
| Parallel Curve (`Constant`, `ParallelMode`) | Offset Curve on Surface (`Distance`, `DistanceMode`) |
| 3D Curve Offset (`PullingDirection`) | Offset Curve 3D (`DirectionRef`) |
| Shape Fillet | Surface Fillet |
| Extract + Multiple Extract | **Extract**: one operator, several rows, per-row propagation (None / Connected / Tangent) and threshold, Complementary |
| Boundary (Point continuity / Complete boundary / Tangent continuity / No propagation) | Boundary Curves (Connected / Whole boundary / Tangent / None) |
| Healing | Heal |
| Close Surface | Make Solid |
| Continuity Position / Tangency (Tangent) / Curvature | G0 Position / G1 Tangent / G2 Curvature |
| Toolbars Structure / Wireframe / Surfaces / Operations / Analysis | **Sets · Curves · Surfaces · Edit · Inspect**, with fly-outs by task: Curve shapes, Curve fillet & bridge, Offset curves, Derive curves, Basic surfaces, Surfaces from curves, Cut & combine, Edges & fillets, Transform |

- Command names are now `GenSurf_<Operator>` (custom shortcuts or
  toolbars that used the old command names need to be re-assigned).
- Menus follow the toolbars, one submenu each.
- Docstrings, tooltips and the README describe GenSurf's own behaviour.
- A feature that still waits for inputs logs an informational message
  instead of a warning.
- README: problems are reported as GitHub issues (the forum thread it
  mentioned was never linked).

### Added
- Algorithm versioning: every feature has a hidden `GenSurfAlgo`
  version. When an operator's mathematics changes, existing objects keep
  their old behaviour; "Upgrade to current algorithm" (context menu,
  shown only on outdated objects) switches one explicitly.
- `gensurf/migrations.py`: the map from old names to new ones, applied
  on document restore; restored properties also pick up current groups,
  tooltips and option lists.
- Icon set in FreeCAD's native style, generated by `tools/gen_icons.py`.
- README screenshots of the demo model, the Blend panel and curvature
  combs; `tools/capture_screenshots.py` retakes them.
- `tools/gui_smoke.py`: a GUI smoke test run inside FreeCAD — every
  command creates its object, opens its panel, applies and cancels; every
  operator's panel opens in edit mode on the 0.28 legacy document.
- `docs/glossary.md`: the terms GenSurf uses.
- `docs/third_party.md`: licences of outside code, with an audit of the
  Curves workbench and the rules for reusing or studying other code.
- `docs/occt_python_exposure.md`: which OCCT features GenSurf can reach
  from Python, each one tested, with what it means for upcoming work.
- `GenSurfError(key, message, faulty_properties, sub_elements, severity)`:
  feature problems carry a stable key, the inputs at fault and a severity
  (Error, Warning, Info). Every recompute records them on the feature for
  the task panel; operators can report non-fatal warnings while still
  producing geometry. `GSFeatureError` remains as an alias. The task
  panels name the inputs at fault after the message.
- Tests: old documents recompute identically (the demo file and a 0.28
  document holding every renamed operator and mode), migration
  mechanisms, an identity lint, a static check of the command,
  toolbar and icon layout, and a measurement showing that Blend's G2
  mode matches the support's curvature across the edge (0.18 %).

### Fixed
- Offset Curve 3D switched sides where the curve runs parallel to the
  direction (for example a curve whose own plane contains the
  direction), giving a kinked result. New objects keep one side and warn,
  with a hint when the direction lies in the curve's plane. Existing
  objects keep their geometry (algorithm version 1) but now warn, and
  "Upgrade to current algorithm" applies the fix. Reported on the forum.
- Documents saved without GUI data (scripts, tests, older files) showed
  generic tree icons, and double-clicking a GenSurf feature did not open
  its task panel: GenSurf's view providers are now attached whenever a
  document becomes active.
- A new Line no longer prints an error before its first point is picked.
- Task panels did not open on FreeCAD 1.1: PySide6 Qt enums no longer
  convert with `int()`, so the OK / Apply / Cancel buttons failed for
  every operator. A regression test now checks the conversion.
- A Blend saved before 0.25 (no `Borders` property) no longer changes
  shape on recompute: it restores with `Borders = Natural`, the
  behaviour it was built with.
- Sweep Curve, 2 rails mode: no longer fails when the profile's chord is
  parallel to the chord between the rails (some FreeCAD builds return a
  NaN rotation for parallel vectors).

## [0.28.0] — 2026-07-25

### Added
- Heal: geometry repair, small-edge removal, merging of faces lying on
  the same surface, regularity encoding.
- Curvature Comb analysis of curves.
- Split and Trim: a fuzzy boolean `Tolerance` for near-touching geometry.

### Changed
- Fill rebuilt on OCCT's constrained filling: true per-edge G0 / G1 / G2
  continuity against the support faces (the plate-surface path remains
  as a fallback).
- Task panels run as real document transactions: OK commits, Cancel
  aborts, one undo step per feature.
- Linked inputs resolve through `Part.getShape` (safe with App::Link and
  containers), with `getElement` as fallback.

## [0.27.0] — 2026-07-25

### Changed
- Inputs consumed by an operator are hidden on OK (Join, Edge Fillet,
  Chamfer, Trim, Extend, transforms; Split hides the split element but
  keeps the cutter visible).
- Sequential picking: after each pick the next empty input arms
  automatically, optional supports included.
- Live preview is cancel-safe when editing an existing feature.

## [0.26.0] — 2026-07-25

### Fixed
- Twenty correctness and robustness fixes, among them: negative second
  length on Extrude and Revolve; Trim keeps curve pieces in mixed
  surface/curve trims; datum planes follow the face's true normal;
  Extend respects edge trim ranges and supports negative lengths; Loft
  G2 end supports merge correctly at both ends; Boundary Curves limits
  cut by arc length; offset curves walk wires in travel order; Surface
  Fillet keeps one-sided trims; Sweep Curve validates the spine it
  actually follows.
- Degenerate inputs raise clean feature errors instead of raw
  exceptions; Extrude's direction mode survives document restore.

## [0.25.0] — 2026-07-24

### Added
- Blend `Borders`: the side edges either continue the supports' own
  border edges or leave naturally along the coupling direction.

## [0.24.0] — 2026-07-24

### Added
- Make Solid: closed sets of surfaces become solids; planar openings are
  capped with flat faces.

## [0.23.0] — 2026-07-24

- First public release: 39 parametric operators (curves, surfaces,
  sweeps with four profile types, edit operations), sets with an
  active-set workflow, pick-driven task panels, fly-out toolbars and 166
  headless regression tests.
