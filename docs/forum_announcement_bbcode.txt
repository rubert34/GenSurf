Hello everyone,

I'd like to share a new workbench I've been building: [b]GenSurf; Generative Surfaces for FreeCAD[/b].

[size=150][b]What is "Generative Shape Design"?[/b][/size]

If you've never used advanced parametric CAD tools with generative modelling like Pro-E, Solidworks, NX, CATIA etc: this type of workbench is the surfacing environment that much of the automotive and aerospace world models in every day. Its working method is different from solid-first CAD. You build [b]construction wireframe first[/b]; points, lines, planes, projections, intersections, parallels, spines; and then stretch [b]styling surfaces[/b] over that skeleton: sweeps, multi-sections, blends, fills. Everything stays parametric, and everything is organised in [b]Geometrical Sets[/b], so the construction geometry that got you there stays cleanly separated from the surfaces you actually care about. Once you've worked this way, it's hard to go back; it is, in my view, the most efficient surfacing workflow ever put in a CAD package.

GenSurf brings that workflow to FreeCAD, natively, on FreeCAD's own parametric core; nothing external, just Part/OCC and FeaturePython.

[size=150][b]What's in it today[/b][/size]

39 parametric operators across CATIA-style toolbars with fly-out button groups:

[list]
[*][b]Wireframe:[/b] Point, Line, Plane, Projection, Intersection, Circle (five definition types), Corner, Connect Curve, Spline, Helix, Spine, Parallel Curve, 3D Curve Offset
[*][b]Surfaces:[/b] Extrude, Revolve, Sphere, Offset, [b]Swept Surface in all four profile types[/b] (Explicit / Line / Circle / Conic; the conic sweep produces true rational conic sections), Fill, Multi-Sections (with per-section and per-guide support surfaces and G0/G1/G2 continuity), Blend
[*][b]Operations:[/b] Join, Split, Trim, Boundary, Extract, Multiple Extract, Shape Fillet, Edge Fillet, Chamfer, Translate, Rotate, Scale, Symmetry, Extend (with mathematically [i]natural[/i] extrapolation; the way Rhino extends, not the odd flattening some packages do)
[/list]

Each operator gets a CATIA-style task dialog: click the tool, pick your inputs in the 3D view, set parameters, Preview/OK. Features idle quietly until their inputs are complete instead of erroring, and geometrical sets capture new sketches automatically.

[size=150][b]About the project[/b][/size]

The goal is serious: a surfacing environment that aims at the efficiency of the professional packages like CATIA, Solidworks, NX; rather than a collection of scripts. Concretely that means: strict advanced-professional CAD fidelity behaviours (operator by operator, dialog by dialog), one self-contained parametric feature per operator, and a suite of [b]166 headless regression tests[/b] that verify the actual mathematics (continuity conditions, conic exactness, propagation semantics, extrapolation) against FreeCAD's core on every change. Where an option isn't implemented yet, the operator's documentation says so explicitly; nothing is silently approximated.

Full disclosure on the development method, because I believe in being upfront: the implementation work is done with Claude (Anthropic's AI) as the coding engine. Every line is exercised by the numeric test suite before it ships. Judge the tool by what it does; the repository and tests are open.

[b]Repository / installation:[/b] [url]https://github.com/rubert34/GenSurf[/url]
Install via the Addon Manager (add the repository URL as a custom repository) or copy the folder into your Mod directory. FreeCAD 1.0+. License: LGPL-2.1-or-later.

[size=150][b]Found a problem? Here's how to report it so it gets fixed[/b][/size]

Post it in this thread with three things:

[list=1]
[*][b]What you were trying to achieve[/b]; the modelling intent, not just the button you pressed;
[*][b]What actually happened[/b]; a screenshot, the error text from the Report view if any, and ideally the .FCStd file (or a minimal version of it);
[*][b]What you expected to happen[/b]; especially valuable if you know how CATIA/Solidworks behaves for the same operation.
[/list]

Reports in that format are usually reproducible immediately, and reproducible issues get fixed fast.
