# Third-party code and licences

GenSurf is licensed LGPL-2.1-or-later. This page records every piece of
outside code GenSurf uses or might use, and the rules for each.

> Not legal advice. The reasoning below follows the usual reading of the
> licences; get a lawyer's review before relying on it commercially.

## What GenSurf contains today

No third-party code is copied into GenSurf.

| Item | Licence | How GenSurf uses it |
|---|---|---|
| FreeCAD and OpenCASCADE (OCCT) | LGPL-2.1-or-later / LGPL-2.1 with exception | The host application; not distributed with GenSurf |
| pythonocc-core | LGPL-3.0-or-later | Not used. Present in some FreeCAD builds only; see `occt_python_exposure.md` |
| Icons (`resources/icons`) | GenSurf's own | Generated by `tools/gen_icons.py` |
| Test documents (`tests/data`) | GenSurf's own | Built with GenSurf |

## Curves workbench audit

Repository `tomate44/CurvesWB`, commit `c08e21b` (12 October 2026),
read on 19 October 2026. 120 Python files.

| Files | Licence | Copyright | Reuse in GenSurf |
|---|---|---|---|
| 107 files with an `SPDX-License-Identifier: LGPL-2.1-or-later` header (author and maintainer: Christophe Grellier) | LGPL-2.1-or-later | the author | **Allowed**, same licence as GenSurf. Keep the file's copyright and SPDX lines, mark GenSurf's changes, and add a row to the table below |
| `freecad/Curves/gordon.py`, `BSplineAlgorithms.py`, `BSplineApproxInterp.py`, `curve_network_sorter.py` — the Gordon-surface (curve network) engine | Apache-2.0 (`LICENSE-TIGL`), derived from TiGL | 2018 German Aerospace Center (DLR) | **Owner's decision needed.** Apache-2.0 is compatible with version 3 of the (L)GPL but not with version 2, so a GenSurf release containing these files could only be distributed under LGPL-3.0-or-later terms (GenSurf's "or later" allows that). Keep the Apache header and licence text, and state the changes |
| 9 files in `freecad/Curves/lib/` without any licence header (`surface_identifier.py`, `face_builder.py`, `curve_identifier.py`, `precision.py`, `surface_builder.py`, `geometry.py`, `point_array.py`, `flatten_face.py`, `trimmed_surface.py`) | presumably the repository's `LICENSE-CODE` (LGPL-2.1) | presumably the author | Ask the author to confirm before reusing |

Consequence for WP 5.1 (Network Surface): the plan's default, a
self-contained implementation written from the published algorithm
(Gordon surfaces, curve-network compatibility), keeps GenSurf under
LGPL-2.1-or-later. A port of TiGL's C++ code is a derivative work under
the same Apache-2.0 terms as the Curves files above.
